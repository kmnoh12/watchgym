# 심박 존 비교 시안 8개

2026-10-18 사용자 피드백에 따라 현재 존 중앙 정렬을 유지하며 글자, 주변 표식, 선택 형태를 A~H로 비교한다. 모두 심박 112/Zone 2, 32:10/9세트의 동일한 정적 시안이다. 앱 구현과 존 판정은 변경하지 않는다. 후보 선택 후 존 전환과 화면 수명 주기를 기존 앱의 애니메이션 경로에 반영한다.

`python3 build.py`로 독립 HTML을 생성한다. 실제 Chrome에서 Roboto/Noto Sans KR 로드 후 8개 화면을 확인했고 390px에서 가로 넘침이 없음을 확인했다. 정적 시안이므로 존 전환 모션 검증이나 실기기 결과를 뜻하지 않는다.
