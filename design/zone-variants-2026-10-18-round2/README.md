# 심박 존 추가 시안 I–P

사용자 지시: 표기는 `Zone 2` 또는 `ZONE 2`로 고정. 기존 A–H와 다른 형태 8개를 추가한다. 앱 코드는 변경하지 않았다.

같은 워치 화면에 커팅 리본, 아웃라인 캡슐, 진행 띠, 낮은 대비 면/세로선, 포인터/점, 아크, 매트릭스, 사이드 레일을 비교한다. 라벨/주변 표식의 간격을 실제 렌더에서 확인했다. 390px에서 페이지 가로 넘침이 없고 모든 시안에 완전한 영문 존 라벨이 있다. 정적 후보이며 전환 애니메이션 검증 결과는 아니다.

`python3 build.py`로 HTML을 생성한다. 기존 공통 워치 얼굴과 SVG 기본 함수를 재사용한다.
