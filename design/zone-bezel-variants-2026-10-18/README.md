# 베젤 존 시안 Q–T

사용자 요청: 존 선을 베젤 끝으로 옮겨 심박 숫자 아래쪽에 배치하고, 운동 시간·완료 세트를 위로 올린 4개 후보.

네 안 모두 432 격자의 반지름 207 안쪽에 존 표시를 배치한다. Zone 2 텍스트 baseline 205, 두 통계 baseline 274/303으로 기존 324/353보다 50 위로 이동했다. Q는 긴 호, R은 짧은 눈금과 긴 현재 존, S는 방사형 눈금, T는 좁은 범위와 단색 보조 눈금이다. 현재 존은 기존 Zone 2/112 bpm 예시를 쓴다.

Roboto/Noto Sans KR 로드 후 Chrome에서 렌더를 확인했고 390px 페이지 가로 넘침이 없었다. 정적 후보만 생성했으며 앱 코드/존 판정/전환 동작은 변경하지 않았다. `python3 build.py`로 재생성한다.
