# 워치짐 디자인 언어 (2026-10-12)

한 줄 요약: **숫자가 주인공인 어두운 화면.** 장식은 빼고, 운동에서 실제로 나온 숫자(경과일, 볼륨, 반복 수, 템포)를 크게 보여준다. 포인트색은 민트 하나.

## 왜 새로 짜는가

플랫폼 하나(플릭)의 구조만 따라가면 세부 모양까지 닮아 버린다. 그래서 동작 아이디어는 여러 앱에서 가져오고, 모양은 우리 데이터에서 끌어낸다. 복원한 코드와 에셋은 쓰지 않는다.

## 본 앱들에서 가져온 것과 우리 방식

| 본 것 | 어디서 | 우리가 취한 아이디어 | 우리 식 구현 |
|---|---|---|---|
| 세트 줄에 지난번 값이 연하게 붙음 | Hevy | 입력하는 순간 비교 대상이 보이는 것 | 세트 번호 아래에 지난번 값을 작게(별도 열은 두지 않음), 완료하면 줄 전체가 민트 워시로 바뀜 (구현됨) |
| 신기록 순간을 크게 축하 | Fitbod | 기록 갱신을 놓치지 않게 | 세트 완료 때 숫자 한 줄로 알림, 결과 화면에서 갱신 항목 강조 (예정) |
| 몸 그림에 근육별 볼륨 | 짐워크, Fitbod | 어떤 부위를 했는지 한눈에 | 민트 한 색의 농도로 표시 (예정) |
| 한 세트씩 큰 숫자로 보는 집중 화면 | 플랜핏 | 운동 중엔 숫자 하나만 | 워치가 센 반복 수를 실시간으로 크게 (우리만의 강점, 예정) |
| 주간 목표 링/요일 | Fitbod, Gym+ | 이번 주 진행을 바로 확인 | 요일 막대, 높이 = 운동 시간과 세트 수를 합친 부하 |
| 워치 코칭을 전면에 | 짐워크, 플랜핏, Fitbod | 워치 연동이 핵심 판매 포인트 | 우리는 손목 센서로 반복·템포·궤적을 측정 |
| 스토어 이미지의 굵은 한글 헤드라인 | 짐워크, 플랜핏 | 한 화면, 한 메시지 | 화면 제목은 짧게, 큰 숫자 하나로 시선 고정 |

피한 것: 라임/형광 포인트에 꽉 찬 추천 카드(Gym+), 왼쪽 색 줄 카드, 알약형 버튼과 칩, 장식 그라데이션, 모든 행에 반복되는 같은 아이콘, 둥근 카드를 줄줄이 쌓은 목록.

## 워치 화면 (2026-10-18) — 기준은 `design/watch-ui-2026-10-17/index.html`

시안 파일이 기준이고 앱 코드는 시안과 픽셀 단위로 맞춘다. 시안 파일의 색 토큰(`:root`)은 앱의 색 상수(`WatchWorkoutFace` 컴패니언)와 같은 값이다. 좌표는 원형 432 격자, 글자는 `designSp = 시안 크기 / 2`, 줄 상자(`line-height:1`)의 기준선은 위에서 `0.841 × 크기`.

- **측정(1·2번, 시안 1-B)**: 이름 아래 한 줄 `● 1세트 · 20kg · 자동 측정`에서 세트와 무게만 흰색(뼈색)·medium, 나머지 흐림. 무게가 없으면 무게 칸은 뺀다(`setStatusLine`). 구분선 아래는 심박 하나만: 하트 35.6, 숫자 37.4(medium), `bpm` 20(흐림), 6 간격, 가운데 정렬, 기준선 373. 가운데 세로선 없음.
- **휴식(4a)**: 시계(42) 아래 시간 108 굵게(줄 상자 72, 기준선 162.8, 자간 −3), 10초 막대(x 48~384, y 182~262, 모서리 22, 글자 46, 노브 140×68 글자 36 굵게), 정지·건너뛰기(138×70, 모서리 22→20, 글자 24, x 67·227, y 280~350). "휴식 · 목표", 다음 세트 카드, "다음 세트 시작" 글자, 아래로 끌어 건너뛰기는 없앴다.
- **휴식 정지(4-1)**: 정지를 누르면 140ms 동안 93%로 눌리며 어두워지고(밝기 0.8), 340ms(`cubic-bezier(.22,.8,.3,1)`) 동안 한꺼번에 바뀐다. 버튼은 노란 "계속", 시간은 85%로 줄며 12 내려가고 노랑에서 흰색, 링 호는 35%, 위에 "휴식 · 일시정지"가 뜨고, 10초 막대는 35%로 흐려지며 안 먹고, 아래 화살표는 사라진다. 건너뛰기는 정지 중에도 된다. 구현은 `WatchWorkoutFace.restMorph`, `RestPill`, `MainActivity.morphRest`.
- **페이지**: 위로 세트 편집(휴식 중엔 "다음 세트"가 먼저 선택됨), 아래로 심박 장(측정 중과 휴식 중 모두, 정지 중엔 센서가 꺼져 없음). 화살표는 존재하는 쪽만 보인다.
- **시작**: 워크아웃 세트는 시작 직후와 휴식이 끝난 직후, 손목이 3초 연속으로 거의 안 움직여야 시작 진동("딩딩")이 울리고 센서 측정이 시작된다(`StartPoseStabilityGate`, `WORKOUT_HOLD_MS`). 대기 중 화면은 "준비 · 손목을 잠시 멈춰 주세요", 폰은 "손목 안정 확인 · 흔들림 없이 3초 유지". 이 대기를 우회하는 시간 제한은 일부러 두지 않았다.
- **세트 종료**: 목표를 못 채웠으면 마지막 렙 뒤 7초 동안 렙이 없어야 끝나고, 채운 뒤(딩딩딩)에는 3초다(`SetEndGate.waitNs`). 학습된 대기가 7초보다 길면 그대로 쓴다.
- **목표 초과·휴식 편집·보조 장 마무리(10/18 소스)**: 링은 시안과 같은 432 격자의 반지름 209·두께 7로 통일했다. 편집 버튼은 시안의 600 굵기, 선택 세그먼트는 700·비선택은 500이다. 편집 면 `#1C1B19`, 일반 조절 `#34322D`, 큰 조절 `#4B4841`, 과거 선택 `#403E3A`를 구분한다. 다음 세트 선택은 세이지 글자와 `#0F2A22`, 방금 세트 선택은 뼈색 글자다. 시안·앱을 함께 정리했으며 레이아웃과 4a·4-1 모션은 유지했다.
- **심박 샘플**: 118bpm은 현행 기준(참조 최대 심박 185)에서 ZONE 2다. 2번 시안의 하트만 파랑으로 정정했고 구간 계산·센서 정책은 바꾸지 않았다. 보조 장의 112bpm·Zone 2, 32:10·9세트 값은 유지하며 최신 배치는 아래 사진 기준 절을 따른다.

관절만 이어서 그린 단순한 뼈대다. 몸을 3D 관절(어깨, 팔꿈치, 손목, 엉덩이, 무릎, 발목)로 정의하고 카메라 정책의 시점(앞쪽 45도, 랫풀다운류는 뒤쪽 45도, 플라이·레터럴은 정면)만큼 돌려 화면에 투영한다. 선은 팔 길이의 3% 굵기의 반투명 흰색이고 자세가 맞으면 초록이다. 손목이 머리에 가려지는 운동(오버헤드 익스텐션)은 손목 신뢰도 기준을 0.25로 낮춘다. 자세를 바꾸면 `CameraStartPoseHarnessTest`가 졸라맨의 3D 관절이 앱의 시작 판정을 통과하는지 확인한다.

## 글자

- 숫자(경과일, 볼륨, 반복 수, 시계)는 크게, 굵기 Medium, 자간 살짝 좁게. 라벨은 11~13sp 보조색.
- 한 화면에서 큰 숫자는 하나가 주인공. 나머지는 한 단계 작게.
- 안내·질문은 해요체, 버튼·라벨·상태는 명사형 단답을 쓴다. 아래 문구 규칙과 `KoreanToneTest`를 따른다.

## 아이콘

글리프(⌂ ▣ ⚡ ⋮ ⓘ 등)는 환경마다 다르게 그려져서 싸 보인다. 직접 그린 선 아이콘으로 통일한다 (`ui/Icons.kt`): 24 격자, 선 굵기 1.75, 둥근 끝, 꽉 찬 도형 없음.

## 모션 (`Motion`)

패널 300ms easeInOutCirc, 작은 변화 200ms easeInOut, 숫자는 linear 롤링, 스프링·바운스 없음. 단, 기록 갱신 순간(폰 결과·워치 7·8번)만 예외: 오늘 막대가 위로 올라오고 새로 늘어난 점은 한 번 튕기며(스프링 한 번) 생긴다. 모션 줄이기 설정이면 완성된 모양으로 바로 보인다. 새 화면이 열릴 때 숫자와 막대는 한 번 자라난다 (`rememberEntered`).

## 화면별 규칙

1. 홈: 이번 주 요일 막대 → 가장 오래 쉰 루틴(큰 숫자) → 루틴 목록(구분선, 경과일 숫자) → 하단 버튼 하나만 채움.
2. 루틴 상세: 큰 근육 그림 칸 → 운동 행(구분선) → 하단 시작 버튼 하나만 채움.
3. 운동 화면: 위에서 아래로 이미지 → 이름 → 목표/수행 → 볼륨 막대 → 지난번/다음 목표 → 세트 표. 세트 표는 "지난번" 열이 있고 완료 줄은 워시.
4. 휴식: 링은 민트 한 색, 숫자는 롤링.
5. 시트/팝업: 아래 시트 위쪽 16dp, 팝업 10dp, 버튼은 텍스트 또는 채움 하나.
6. 기록/통계: 달력만 카드, 나머지는 구분선 목록과 큰 숫자.

## 문구 규칙 (해요체 + 명사형)

- 버튼, 라벨, 상태는 명사형 단답: 시작, 추가, 삭제, 취소, 운동 완료, 세트 추가 / 휴식 중, 연결 안 됨, 저장 완료.
- 안내, 질문, 알림은 해요체: "운동을 종료할까요?", "순서를 바꿨어요", "연결을 확인해 주세요".
- 반말(~했어, ~해줘, ~할까?, ~돼)과 합쇼체(~합니다, ~하시겠습니까)는 쓰지 않는다. 느낌표와 이모지도 쓰지 않는다.
- 확인 팝업: 제목은 질문, 본문은 결과, 버튼은 구체적인 동사 두 개(계속 운동 / 종료).
- 오류: 무슨 일인지 한 줄, 해결 방법 한 줄.
- 용어 고정: 세트, 회, 무게, 볼륨, 휴식, 루틴, 운동. "삭제"(제거 아님), "종료"(중단 아님), "센서 기록"(원본·capture 아님).
- `core/src/test/.../KoreanToneTest`가 모든 한국어 문구를 훑어 위반이 있으면 테스트를 실패시킨다. 새 문구를 쓸 때 이 테스트가 기준이다.

### 보조 화면 심박 존 — 2026-10-18 제공 사진 기준

중앙의 큰 선택 바와 Q–T 시안은 사용자가 채택하지 않았다. 최종 방향은 사용자가 제공한 원형 워치 심박 화면을 따른다. 위에는 기존 운동 시간·완료 세트를 두고, 가운데에는 뼈색의 큰 심박 숫자와 존 색 하트, 아래에는 `Zone 2`와 하단 반원 게이지를 둔다. 표기는 `Zone N`이며 Z2/존2 같은 축약을 쓰지 않는다. 새 평균/최대 심박 데이터는 만들지 않았다.

432 격자에서 상단 라벨 baseline 101/숫자 140, 구분선 y=166, 심박 숫자 baseline 280/크기 96, 존 표기 baseline 345/크기 24다. 게이지는 중심 (216,216), 반지름 194·선 두께 7의 하단 180도에 다섯 구간으로 이어진다. 현재 구간은 밝게, 나머지는 약 25%로 표시하고 흰 점이 실제 수신 심박의 게이지 위치를 가리킨다. 점 위치와 구간 강조/존 글자 색은 320ms 동안 이어지며 같은 존 안의 심박 변화도 점을 이동시킨다. 빠른 연속 변경은 현재 표시에서 이어가고 화면 분리 시 애니메이션을 정리한다. 초기 표시/시스템 애니메이션 비활성화는 즉시 최종 위치다.
