# 뉴텍 국내 공식 제품 목록과 워치짐 머신 명칭 기준안

확인일: 2026-10-25 (한국). 출처: [뉴텍웰니스 국내 공식 홈페이지](https://www.ntws.co.kr/).
공식 PRODUCT 메뉴의 10개 제품 라인 목록에서 상품 링크 기준 138개를 수집했다. 벤치·랙·복합 케이블 기구도 포함하므로 138개 모두를 단일 운동 머신으로 해석하지 않는다. 페이지에서 별도 page 파라미터 링크는 발견되지 않았다. 온라인 공개 목록의 스냅샷이며 비공개/판매 종료 제품까지 포함한 회사 전체 SKU의 완전성을 주장하지 않는다. `일시 단종` 표시는 원문대로 보존했다.

공식 상품 원명/라인 분류는 아래 목록이며, 다음의 한국어 이름과 정렬 규칙은 **워치짐에 대한 제안**이다. 앱 명칭/정렬/운동 ID는 이번 조사에서 변경하지 않았다.

## 관찰한 규칙

- 제품을 ON HIM, ADVANCE, M-TORTURE 등 라인별로 나눈다.
- 이름에 동작과 필요한 자세/방향을 포함한다. 예: Seated Row, Low Row, High Row, Vertical Pull Down, Incline Chest Press, Seated/Standing Lateral Raise.
- 라인별 목록 순서가 같지는 않다. ON HIM은 가슴 계열로, M-TORTURE는 등 계열로 시작한다. 제조사 홈페이지 순서를 앱의 공통 정렬 규칙으로 그대로 가져올 수는 없다.
- 같은 제품군 안에서도 Pec Dec / Pec Deck, Pull Down / Pulldown 같은 표기 차이가 보인다. 원문은 보존하되 앱 표기는 따로 통일한다.
- 같은 라인의 제품이라는 이유만으로 서로 같은 운동이거나 같은 측정 조건이라고 보지 않는다. 제조사 이름은 실제 운동/기구 구조를 확인하는 참조 자료다.

## 앱에 제안하는 표기

머신 이름: `[원암] 머신 [필요한 자세·방향] [동작명] (핀식/플레이트식)`.
중량 방식은 확인된 종목에만 붙이고, 현재 정보가 없는 과거 기록을 임의로 핀/플레이트에 배정하지 않는다.
브랜드/시리즈/제품 코드는 별도 참고·검색 별칭으로 두고, 표시 운동명을 뉴텍 전용 이름으로 일괄 변경하지 않는다.

| 명칭 종류 | 통일 예시 |
|---|---|
| 양손 핀식 | 머신 시티드 로우(핀식) |
| 원암 핀식 | 원암 머신 시티드 로우(핀식) |
| 양손 플레이트식 | 머신 시티드 로우(플레이트식) |
| 원암 플레이트식 | 원암 머신 시티드 로우(플레이트식) |
| 다른 당김 방향 | 머신 하이 로우(플레이트식) / 머신 로우 로우(플레이트식) |
| 프레스 각도 | 머신 인클라인 체스트 프레스(플레이트식) |
| 케이블 손잡이 운동 | 케이블 랫풀다운 / 케이블 시티드 로우 |

- `원암` / `랫풀다운` 띄어쓰기를 고정한다. `원 암`, `랫 풀 다운`, `랫 풀다운`을 표시명에서 섞지 않는다.
- 머신은 `머신` 접두어를 고정하고 `플레이트`만 앞에 붙이는 표기와 섞지 않는다.
- 시티드/스탠딩, 인클라인/디클라인, 하이/로우, 가슴 지지처럼 실제 수행 조건을 바꾸는 구분은 남긴다.
- 핀/플레이트는 중량 설정 방식이다. 케이블 풀리와 고정 손잡이 레버의 차이를 대신하는 분류가 아니다. 제품 사진/상세를 확인해서 서로 다른 동작을 임의로 합치지 않는다.
- 레터럴 레이즈/사이드 레터럴/사레레 등 익숙한 표현은 검색 별칭으로 받을 수 있다. 원문 제품명은 출처 대조용으로 보존한다.

## 앱에 제안하는 정렬

기존 부위 분류 → 동작군 → 기구 종류 → 중량 방식(핀식, 플레이트식) → 양손, 원암.
화면에 원암 접두어를 붙여도 문자열 가나다순으로만 정렬하지 않아 같은 운동의 양손/원암이 나란히 오도록 한다.
예: 머신 풀다운(핀식), 원암 머신 풀다운(핀식), 머신 풀다운(플레이트식), 원암 머신 풀다운(플레이트식).
